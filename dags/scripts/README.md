# Генератор логов

Python-скрипт для генерации больших объемов логов в форматах Apache/Nginx (access.log) или JSON. Поддерживает создание "грязных" данных с проблемами в формате для тестирования обработки логов.

## Возможности

- **Генерация 1+ млн строк логов** с высокой производительностью
- **Два формата вывода**: Apache/Nginx Common Log Format и JSON
- **"Грязные" данные**: 5% строк содержат проблемы (невалидный формат, отсутствующие поля, null значения и т.д.)
- **Гибкая настройка** через параметры командной строки
- **Воспроизводимость**: поддержка seed для генератора случайных чисел
- **Прогресс генерации**: отображение статуса при использовании флага `--verbose`
- **Оптимизация**: батчевая запись для эффективной работы с большими файлами

## Установка и требования

Требуется Python 3.6 или выше. Дополнительные зависимости не требуются.

# Скрипт готов к использованию
python3 log_generator.py --help

## Использование

### Базовый синтаксис

```bash
python3 log_generator.py [--format apache|json] [--output FILE] [--lines N] 
                 [--seed SEED] [--verbose] [--batch-size N] [--dirty-percent P]
```

### Параметры командной строки

| Параметр | Сокращение | Значение по умолчанию | Описание |
|----------|------------|----------------------|----------|
| `--format` | `-f` | `apache` | Формат логов: `apache` или `json` |
| `--output` | `-o` | автоматическое имя | Выходной файл (если не указан, генерируется автоматически) |
| `--lines` | `-l` | `1000000` | Количество строк для генерации |
| `--seed` | `-s` | случайный | Seed для генератора случайных чисел (для воспроизводимости) |
| `--verbose` | `-v` | `False` | Выводить прогресс генерации |
| `--batch-size` | - | `10000` | Размер батча для записи в файл (оптимизация производительности) |
| `--dirty-percent` | - | `5.0` | Процент "грязных" данных с проблемами (0-100) |

### Примеры использования

#### 1. Генерация 1 млн строк Apache логов с 5% "грязных" данных
```bash
python3 log_generator.py --format apache --output access.log --lines 1000000 --dirty-percent 5
```

#### 2. Генерация 500k JSON логов с воспроизводимым seed
```bash
python3 log_generator.py --format json --output logs.json --lines 500000 --seed 42
```

#### 3. Генерация Apache логов с 10% "грязных" данных и выводом прогресса
```bash
python3 log_generator.py --format apache --lines 10000 --dirty-percent 10 --verbose
```

#### 4. Генерация JSON логов с большим batch size для оптимизации
```bash
python3 log_generator.py --format json --lines 1000000 --batch-size 50000 --output big_logs.json
```

#### 5. Генерация чистых логов (0% "грязных" данных)
```bash
python3 log_generator.py --format apache --lines 100000 --dirty-percent 0 --output clean_access.log
```

#### 6. Просмотр всех доступных параметров
```bash
python3 log_generator.py --help
```

## Форматы вывода

### Apache/Nginx Common Log Format (расширенный)

```
IP - user [timestamp] "METHOD URL PROTOCOL" STATUS SIZE "REFERRER" "USER_AGENT" RESPONSE_TIME
```

Пример:
```
192.168.1.1 - - [21/May/2026:14:22:13 +0300] "GET /index.html HTTP/1.1" 200 1234 "-" "Mozilla/5.0..." 142
```

**Поля:**
- `IP` - IP-адрес клиента
- `user` - имя пользователя (если используется аутентификация)
- `timestamp` - дата и время запроса
- `METHOD` - HTTP метод (GET, POST и т.д.)
- `URL` - запрашиваемый URL
- `PROTOCOL` - HTTP протокол (HTTP/1.0, HTTP/1.1, HTTP/2)
- `STATUS` - HTTP статус код
- `SIZE` - размер ответа в байтах
- `REFERRER` - реферер
- `USER_AGENT` - пользовательский агент
- `RESPONSE_TIME` - время ответа в миллисекундах

### JSON формат

Каждая строка содержит отдельный JSON-объект:

```json
{
  "timestamp": "2026-05-21T14:22:13",
  "ip_address": "192.168.1.1",
  "user": "-",
  "method": "GET",
  "url": "/index.html",
  "status_code": 200,
  "response_time_ms": 142,
  "size": 1234,
  "referrer": "-",
  "user_agent": "Mozilla/5.0...",
  "protocol": "HTTP/1.1"
}
```

## "Грязные" данные

Скрипт может генерировать строки с проблемами для тестирования обработки логов. Типы "грязных" данных:

### Для Apache формата:
- **Неполные строки** (обрываются посередине)
- **Лишние поля** или разделители
- **Неправильный порядок** полей
- **Незакрытые кавычки**

### Для JSON формата:
- **Невалидный JSON** (пропущенные запятые, незакрытые кавычки)
- **Null значения** в обязательных полях
- **Отсутствующие поля**
- **Лишние/нестандартные поля**
- **Незакрытые фигурные скобки**

Процент "грязных" данных контролируется параметром `--dirty-percent` (по умолчанию 5%).

## Производительность

Скрипт оптимизирован для генерации больших объемов данных:

- **Батчевая запись**: данные накапливаются в памяти и записываются пачками (размер контролируется `--batch-size`)
- **Генераторные функции**: использование yield для экономии памяти
- **Эффективные структуры данных**: предварительно инициализированные пулы данных

**Ориентировочная производительность:**
- ~50,000-100,000 строк/сек на среднем оборудовании
- 1 млн строк генерируется за 10-20 секунд
- Потребление памяти: ~50-100 МБ при генерации 1 млн строк

## Классы и архитектура

### `LogGenerator` (базовый класс)
- Инициализация источников данных (IP-адреса, user agents, URL пути и т.д.)
- Генерация базовой записи лога в виде словаря
- Поддержка "грязных" данных с заданной вероятностью

### `ApacheLogGenerator`
- Форматирование записей в Apache Common Log Format
- Обработка "грязных" данных специфичных для текстового формата

### `JsonLogGenerator`
- Форматирование записей в JSON (одна строка = один JSON-объект)
- Обработка "грязных" данных специфичных для JSON

## Использование в качестве модуля

Скрипт можно импортировать как модуль для использования в других проектах:

```python
from log_generator import ApacheLogGenerator, JsonLogGenerator

# Создание генератора
generator = ApacheLogGenerator(seed=42, dirty_percent=5.0)

# Генерация 100 строк
for line in generator.generate(100):
    print(line)
```

## Ограничения

- Максимальный размер файла ограничен доступной памятью и дисковым пространством
- Для генерации более 10 млн строк рекомендуется увеличить `--batch-size`
- Временные метки генерируются в пределах последних 30 дней от текущей даты
